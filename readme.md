# 📚 LireMonde

## 📖 Description

LireMonde est une plateforme de lecture interactive développée en HTML, CSS et JavaScript.
L’application permet d’afficher des livres dynamiquement depuis une API JSON Server.

---

## 🚀 Fonctionnalités

* Affichage dynamique des livres
* Recherche en temps réel
* Filtrage par genre
* Affichage des détails d’un livre
* Liste “À lire”
* Dashboard Admin (Ajouter / Modifier / Supprimer)

---

## 🛠️ Technologies utilisées

* HTML5
* CSS3
* JavaScript
* JSON Server

## ⚙️ Installation

### Installer les dépendances

```bash
npm install
```

### Lancer JSON Server

```bash
json-server --watch db.json --port 3000
```

---

## 📡 API

